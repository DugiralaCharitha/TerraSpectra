# TerraSpectra

Team-based geospatial analysis and machine learning platform.

## Team Structure

- **Team 1 — Machine Learning**: Dataset management, preprocessing, feature engineering, PCA, model training (3D CNN, Vision Transformer), evaluation, checkpoints, and experiment notebooks.
- **Team 2 — Backend**: FastAPI REST APIs, prediction services, business logic, authentication, configuration, logging, tiling pipeline, and inference pipeline.
- **Team 3 — Frontend**: React application, UI components, pages, API integration, state management, charts, timeline, and analytics panels.
- **Team 4 — GIS & Visualization**: Deck.gl, Mapbox, heatmaps, geospatial rendering, satellite layers, overlay generation, coordinate utilities, and GIS assets.
